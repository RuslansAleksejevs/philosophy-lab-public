# Question: Can an agent erase a moral reason by erasing a concern?

AI-selected question within metaethics: If a person deliberately eliminates the concern from which a moral reason can be reached by sound deliberation, does the original reason cease to apply?

Tentative thesis: desire-based theories must distinguish an agent’s ability to alter motivational psychology from normative authority to release herself from an existing requirement. A diachronic constraint on reasons follows if culpable motivational self-alteration cannot by itself cancel an unfulfilled obligation. The argument will test whether internalism can accommodate this constraint without either extending the relevant motivational base historically or accepting reasons independent of present motivational reachability.

This is a question for investigation, not a claim of originality or a completed refutation. The strongest anticipated objection is that wrongfully destroying a reason can be wrong when undertaken while successfully eliminating the later reason, just as wrongfully disabling an ability can remove a present obligation. Sources will be selected to test that objection and nearby internalist treatments.
