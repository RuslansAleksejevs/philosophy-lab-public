## Насколько глубоко изучены судьи

По сохранённому отчёту корпуса: 72 записи источников/попыток получения.
Из них 23 — только метаданные, 27 — чтение фрагментов, 9 — полное чтение,
8 — недоступные, 5 — непрочитанные. Из девяти полных чтений шесть относятся
к содержательным текстам, три — к официальным страницам конкурса.
Из 27 фрагментарных чтений 24 относятся к работам/критике, три — к
биографическим материалам/интервью. Ни одна книга целиком не прочитана.
Это число записей источников, а не полный список всех работ шестнадцати людей.
2520 кандидатных ссылок в библиографическом инвентаре содержат повторы,
навигацию и другие материалы; они не означают 2520 изученных работ.

Пример глубины: [профиль Чалмерса](../research/judges/20260912/profiles/david_chalmers-v1.md)

перечислены в самом профиле. Проверки по отложенной критике для него нет.

## Как использовать без потери происхождения

Выбрать нужный компонент, проверить его известные пробелы и сохранить в новом
раунде точную версию входных файлов. Уже собранные источники и готовые профили
переиспользуются; новому агенту всё равно требуется прочитать выбранный пакет.
Нулевых затрат повторное применение не обещает. Обновления добавляются новой
версией с причиной изменения; старые версии и ошибки остаются в архиве.

Авторы и критики получают только нейтральные инструкции, выбранные источники
или профили и материалы своего эссе. Этот общий указатель предназначен для
координации. При будущей оценке сохранять сведения о том, использовался ли
тот же профиль при доработке оцениваемого текста; проверку переноса качества
на другие оценки планировать отдельно.
