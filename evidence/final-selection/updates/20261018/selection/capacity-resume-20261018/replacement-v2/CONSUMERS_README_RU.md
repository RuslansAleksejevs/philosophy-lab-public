# Сводка и экспорт после двух замен

Новые скрипты принимают общую карту `selection-capacity-resolution.v2` из
`resolver_v2.load_resolution`. В ней должны быть ровно две принятые замены:
`M12-N2` и `M13-N2`, обе из `attempt-002`. Разрешение начать замену или карта
только одного готового отзыва не подходит. Старые скрипты и версия v1 сохранены.

- `summary_capacity_v2.summarize(run_dir, resolution)` возвращает `(coverage, summary)`.
  Для 108 обычных отзывов вызывается прежний `verify_job`; для двух замен работают
  отдельные проверки точных файлов, сессии и связей архива. Сводка появляется
  только при 110 принятых отзывах. Две ошибки указаны отдельно:
  `preserved_failed_attempts: 2`. Дополнительных голосов они не создают.
- `export_capacity_v2.build(spec, root, resolution)` возвращает предложенный список
  файлов. Формат `spec` остаётся `explicit-selection-final-files.v1`.
  Общий `resolution.evidence_files` должен включать все безопасные метаданные
  обеих замен без изменения хешей. Они входят в экспорт даже при выключенном
  необязательном слое отзывов. Сырые журналы не добавляются.

Расчёт 60/40 и обработка неизвестной новизны берутся из старого `aggregate`
без изменения. Каждый отзыв остаётся одной из пяти исходных ролей своего эссе.
Квитанции замен сохраняют исходный `input_event_id` и логические evaluation ID;
новые зависимости записаны в `replacement_ready_event_id` и
`failed_attempt_event_id`. Общая карта связывает обе принятые замены. Все четыре
сессии — две неудачные и две принятые — должны различаться. Фиктивные квитанции
попыток 001 не создаются.

CLI обоих скриптов принимает `--map-receipt` и читает актуальные события через
`Archive.events/get` для `load_resolution`. Сводка принимает `--run-dir` и новый
`--output-dir`; экспорт — `--root`, `--spec`, новый `--output`.
Ни один consumer не запускает модель, не пишет в архив и не принимает отбор.

Тесты создают только временные искусственные файлы. Подменяется лишь граница
resolver; прежние проверки обычных отзывов и расчёт исполняются без изменения.
Запуск из этой папки: `python3 -B -m unittest test_consumers_v2.py`.
