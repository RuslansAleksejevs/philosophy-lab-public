# The 23 judge profiles

These are the 23 historical instructions used for the October 7, 2026 panel, copied unchanged. Each draws on a philosopher's documented approach; the profiles' fidelity to the real judges remains unvalidated.

The short descriptions below summarize **our instructions**. [Read how the profiles were built and checked.](../docs/judges.md)
